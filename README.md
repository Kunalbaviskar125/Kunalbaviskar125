- 🔄 Iterated through multiple prototype → test → tune → fly cycles

### 🎛️ PID Control

The flight-control system uses PID control to minimize the error between the desired and measured system state.

$$
u(t) = K_p e(t) + K_i \int e(t)\,dt + K_d \frac{de(t)}{dt}
$$

Where:

- **$K_p$** → Proportional gain
- **$K_i$** → Integral gain
- **$K_d$** → Derivative gain
- **$e(t)$** → Error between desired and measured state
- **$u(t)$** → Control output

> **PID tuning was performed iteratively through real hardware testing and flight validation.**
